NATIVE CPU ATTRIBUTION

SkyProfiler

Deep profiling samples Skyrim with Windows ETW. SkyOS will report if Windows has not granted the required profiling privilege. Module and stack shares are estimates, not exact CPU time.

Start deep profile to collect native module samples.

Hot functions and stack frames

Groups samples by Skyrim, third-party modules, graphics drivers, and Windows runtime. Offset-only entries identify an address without a local symbol name.

Function samples are resolved when you stop a profile.
Stopping a run automatically saves SkyMonitor.ini and retains the prior run for comparison.

LOAD ORDER

Loaded plugins

Skyrim's CPU, RAM, and GPU measurements apply to the whole process. ESP/ESM records share engine allocations, so Windows cannot report accurate per-plugin resource usage. SkyProfiler can estimate CPU samples by native DLL module; plugin file size is not RAM use. Recently installed sorting uses the plugin file's last-modified time.
