Mod settings in Skyrim

Configure supported mod settings, themes, and custom module pages through an in-game MCM-style interface; mods remain responsible for applying gameplay changes.

What it doesOpen section

What it does

Open installed mod settings from an in-game menu built with PrismaUI. SkyViewer’s Dwemer panel styling adapts to the active SkyOS theme.

Requirements

For mod creatorsOpen section

For mod creators

Use the SkyOS Modder Starter Kit to create a module folder with a module.json, optional settings page, and logo. Place it under Data/SKSE/Plugins/SkyOS/Mods/SkyViewer/<ModuleId>/.

Manifest settings support boolean, number, text, select, and hotkey types. Numeric controls accept typed values within their declared minimum and maximum, shown below each field. Custom pages run in a sandboxed iframe and communicate with SkyOS through the documented message bridge.

Logos and pagesOpen section

Logos and pages

A module logo placed in its Files folder can appear in the module tab and heading. Keep custom pages self-contained and lightweight for the in-game browser.

TroubleshootingOpen section

Troubleshooting

If a module is absent, check the folder location, JSON syntax, module ID, and log output. SkyViewer reads modules when the UI requests its module catalog; reopen SkyOS after installing a module.

SkyViewer · PrismaUI MCM-style settings menu for supported mods

Use SkyViewer as a player

Open a module

  1. Open SkyOS and select SkyViewer from the navigation rail.
  2. Choose the installed mod module from the module list.
  3. Change the available values; the module page presents controls supplied by that mod.
  4. Return to the app or game feature whose behavior the setting controls.

What a setting changes

SkyViewer displays and stores module preferences. The owning mod is responsible for reading those values and applying the matching behavior. A module option cannot create a feature that the owning mod has not implemented.

Numeric fields

Enter a value directly within the minimum and maximum displayed for that field. The limits describe the valid range; the field should retain a typed value within those bounds.

Theme and app identity

SkyViewer uses SkyOS theme colors while keeping module pages and branding associated with the mod that owns each module.

Module controls for authors

Control typeTypical useNotes
BooleanEnable or disable a feature.Displayed as a switch.
NumberSet a bounded count, duration, interval, or threshold.Declare minimum, maximum, default, and optional step/unit.
TextStore a short free-form value.Use only when a number or select list is not a better fit.
SelectChoose from a fixed set of named values.Options use stable values and readable labels.
HotkeyAssign an in-game shortcut for an app or module.Respect the mod's default and avoid conflicts with other menus.
ActionRun an explicit module action such as resetting a collection.Clearly describe the effect before the player activates it.

Custom pages

Authors can package an optional Files/index.html page and a module logo alongside module.json. Custom pages run in a sandboxed iframe and communicate with SkyOS through the documented message bridge.

Module not listed

Check the module folder path under Data/SKSE/Plugins/SkyOS/Mods/SkyViewer/<ModuleId>/, JSON syntax, module ID, and required app plugin. Reopen SkyOS after installing or changing a module package.
