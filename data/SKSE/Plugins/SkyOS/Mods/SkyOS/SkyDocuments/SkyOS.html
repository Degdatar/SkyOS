What’s includedOpen section

What’s included

  • SkyApps: searchable launcher for SkyOS tools and registered modder apps.
  • SkyViewer: an in-game MCM-style settings menu built with PrismaUI for supported mods. Mod authors can expose settings without Papyrus scripts or Creation Kit forms; gameplay behavior remains implemented by the owning mod.
  • SkyDocuments: built-in PDF and webpage library.
  • Optional apps: separately installable SkySearch, SkyMonitor, SkyRewrite, SkyCollection, SkyCounter UI, SkyAchievements, and SkyMissions modules. SkyMissions owns the character dashboard, randomized missions, and SkyStore; that app requires SkyRewrite for gameplay-event tracking, while SkyOS Core remains independent.
  • Appearance: five themes, seven font choices, and per-theme text color controls.

Using SkySearchOpen section

Using SkySearch

Choose one or more categories, enter a name or FormID, and search. Leaving the query blank lists records up to the configured result limit. Use the SkySearch section in SkyViewer to set the limit and result display.

Actions such as teleporting change the game state. SkyOS closes automatically for supported travel actions.

For mod creatorsOpen section

For mod creators

Use the separate SkyOS Modder Starter Kit for manifests, logos, SkyViewer modules, SkyDocuments packaging, and registered app examples. It is a creator requirement, not a requirement for players running SkyOS.

Supported mod pages and documents live beneath Data/SKSE/Plugins/SkyOS/Mods/.

Appearance and inputOpen section

Appearance and input

Open Settings to choose Dark, Light, Cyberpunk, Vampire Neon, or Deep Blue, then select a font and readable text color. Changes apply immediately and are saved locally.

Troubleshooting

If a component is missing, check the active mod profile and game Data paths first. The Settings page reports SkyNet bridge status. Confirm that PrismaUI and SKSE match the running game version.

SkyOS · Mod information and player requirements

Navigate SkyOS

Open and close the shell

Use the configured SkyOS open/hide hotkey, which defaults to F11, to show the interface. Escape is the default close hotkey. Both can be changed through the SkyOS module in SkyViewer. The optional full-screen intro plays only the first time SkyOS opens in a game session; turn it on or off in the SkyOS core module.

Use the left rail

Home shows the launch dashboard. SkyApps lists available apps. SkyViewer opens settings modules, while SkyDocuments opens local guides. Installed optional apps can also have their own rail entries.

Find an app

  1. Open Home or SkyApps.
  2. Search or filter the available app list.
  3. Select an app to launch its page.
  4. Use the owning app's own controls and settings for its features.

Configure appearance

In Settings, choose a theme, font, and readable text color. SkyOS offers five themes and seven font choices; typography colors can be customized per theme and changes apply immediately.

Optional integrations and common issues

SkyNet integration

SkyNet is optional. When its compatible integration is installed, SkyOS can launch the browser. SkyOS can also offer a setting to use its own PDF/webpage reader instead; the related toggle appears only when SkyNet is installed.

App or module is missing

  • Check that the app is enabled in the current mod profile.
  • Confirm the required SkyOS, SKSE, and PrismaUI files are installed for the running game runtime.
  • For a module, verify its folder, module manifest, and files, then reopen SkyOS after installation.

Travel actions

Some SkySearch actions change game state, such as teleporting to a supported actor or cell. SkyOS closes automatically for supported travel actions so the game can resume.

For app authors

The SkyOS Modder Starter Kit documents module manifests, logos, SkyViewer pages, SkyDocuments packaging, and registered app examples. It is not required for players who only use SkyOS.
