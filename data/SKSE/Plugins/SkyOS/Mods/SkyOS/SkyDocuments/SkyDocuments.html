SKYOS CORE · DOCUMENT READER

SkyDocuments

Browse and read locally installed mod guides and references, including HTML, Markdown, and PDF, from the SkyOS shell.

What it does

SkyDocuments browses supported documents installed with SkyOS and compatible mods, then opens them in the running Skyrim interface. Each guide stays with the app or mod that owns it.

Supported files

  • PDF documents.
  • HTML and HTM webpages.
  • Markdown and plain-text documents.

Use the SkyDocuments navigation to select an app, then choose a guide from its document list.

PDF reading

PDF pages are rasterized with PDFium and displayed as page images. This preserves the source page's typography, layout, illustrations, and vector artwork rather than rebuilding the page from extracted text.

Very large or damaged PDFs may take longer to render or use more memory.

Branding and ownership

Document lists can show each owning app's logo and banner. SkyRewrite, SkyCounter UI, SkySearch, and other app guides remain under their own Mods/<AppName>/SkyDocuments folders and packages.

Privacy and local files

Source documents and rendered PDF pages are read locally. SkyDocuments does not upload them. A document from an optional app is loaded from that app's own installation; the reader does not copy its guide into another app's folder.

Requirements

  • Supported Skyrim Special Edition / Anniversary Edition runtime.
  • SKSE.
  • PrismaUI.
  • SkyOS Core.

Related tools

SkyViewer is the MCM-style settings menu built with PrismaUI. Supported mods can expose options there without Papyrus scripts or Creation Kit forms; the owning mod still implements each setting's gameplay behavior.

Open and read a document

Choose a guide

  1. Open SkyDocuments from the SkyOS rail or its configured hotkey.
  2. Select the app or mod whose documents you want to browse.
  3. Choose a listed guide or reference file to open it in the running interface.
  4. Use the reader's page or scroll controls to continue through the document.

Supported formats

  • PDF: rendered page by page with PDFium and shown as page images.
  • HTML/HTM: opened as a webpage in the built-in reader.
  • Markdown and plain text: opened as readable local text documents.

PDF display

Page-image rendering preserves the PDF's typography, layout, diagrams, and vector artwork without reconstructing the page from extracted text. Very large or damaged files can take longer to render or require more memory.

App ownership

Each guide remains in its owning app's Mods/<AppName>/SkyDocuments/ folder and package. SkyDocuments reads the installed file; it does not move another app's documentation into SkyOS.

Files, branding, and privacy

Branding

Document listings can use the owning app's logo and banner so players can identify which app supplied a guide. Branding assets are packaged with that app.

Local reading

SkyDocuments reads source files and renders PDF pages locally. It does not upload documents. A webpage may still link to external sites; those links are handled by the reader or the configured browser integration.

Missing document

Confirm the optional app is installed and its guide is inside the app's own SkyDocuments folder. Reopen the document list after installing or updating an app package.

Slow or blank PDF

Give large PDFs time to rasterize. If a page remains blank, check that the file is readable and try the app's packaged copy or a smaller source PDF.
