Browse the web in game, use the SkyNet home page and shortcuts, and launch SkyNet from SkyOS when the compatibility bridge is detected.

SkyOS integrationOpen section

SkyOS integration

Install the compatible SkyNet integration build to enable the SkyNet Home tile and browser handoff from SkyOS. SkyOS Settings reports whether the bridge is active. SkyDocuments does not depend on SkyNet; its built-in PDF and webpage reader continues to work without it.

For mod creatorsOpen section

For mod creators

SkyOS Modder Starter Kit is only needed when creating SkyOS modules or registered apps. It is not needed to use SkyNet.

Troubleshooting

Check that SkyNet is enabled in the active mod profile, the DLL matches the game runtime, and the compatible bridge is present if launching it from SkyOS. Review the SkyNet release notes for browser-specific dependencies.

SkyNet · Mod information and player requirements

Browse with SkyNet

Open a page

  1. Launch SkyNet from its own in-game entry point, or from SkyOS when the compatible launch bridge is active.
  2. Use the home page shortcuts or enter a web address or search phrase in the address/search field.
  3. Use the browser controls and tabs to move between pages during the session.
  4. Return to the home page or close SkyNet with the controls provided by the installed browser build.

Tabs and session browsing

SkyNet provides tabbed in-game browsing. Tabs keep multiple pages available within the browser session; their behavior and persistence depend on the installed SkyNet build.

Address and search

The address field accepts a page address or a search phrase. Search handling is provided by SkyNet's browser implementation and may follow its configured search provider.

Home shortcuts

Use the built-in home page shortcuts for common destinations. Their availability can change with the SkyNet version and its packaged home page.

Troubleshooting

SkyOS launches SkyViewer instead

Check that the active SkyNet build includes the SkyOS launch bridge and that its launcher entry points to the exported SkyOS app launch function. Confirm bridge status in SkyOS Settings.

Browser does not start

Check that SkyNet is enabled in the active mod profile, its DLL matches the running Skyrim runtime, and its browser dependencies are present. Consult the release notes for the exact installed version.
